# 🤖 Otimização de Processos de RH com IA e ATS — Case EGK

Projeto de extensão universitária desenvolvido para a disciplina **Inteligência Artificial para Devs**. O objetivo deste projeto foi aplicar conceitos de automação, Processamento de Linguagem Natural (PLN) e lógica de sistemas para resolver o problema de triagem massiva de currículos na consultoria **EGK**.

## 📌 O Desafio (Pain Point)
A equipe de Atração de Talentos da EGK (Vinicius Kobayashi e Bruna) enfrentava um gargalo operacional: triagem 100% manual de centenas de currículos diários. Isso gerava esgotamento no time interno e lentidão no feedback para os candidatos da comunidade local.

## 🛠️ Solução Proposta
Desenvolvimento de uma metodologia prática e capacitação da equipe para implementação de fluxos automatizados utilizando Sistemas de Rastreamento de Candidatos (ATS) integrados com IA, focando em:
1. **CV Parsing:** Extração automatizada de dados textuais de currículos.
2. **Match Making:** Cálculo de score de aderência baseado em palavras-chave e competências técnicas (*hard skills*).
3. **Knockout Questions:** Filtros eliminatórios automáticos para agilizar o funil inicial.
4. **Régua de Comunicação:** Automação de feedbacks personalizados por e-mail para 100% dos candidatos.

## 📁 Conteúdo do Repositório
* `/documentos`: Contém o guia prático final entregue à empresa parceira.
* `/scripts`: Códigos conceituais em Python demonstrando a lógica de um motor de triagem por IA (leitura de texto e matching de palavras-chave).
